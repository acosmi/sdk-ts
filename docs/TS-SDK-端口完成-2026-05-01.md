## TS 端口的关键差异 (与 Go 不可避免的偏移)

| 维度          | Go                    | TS                              | 影响                          |
| ------------- | --------------------- | ------------------------------- | ----------------------------- |
| 错误处理      | 多返回值 (val, err)   | throw (类型化 Error 子类)       | 调用方写法 try/catch          |
| 上下文取消    | context.Context       | AbortSignal                     | API 签名: `signal?: AbortSignal` |
| 同步 IO       | os.ReadFile           | fs/promises                     | TokenStore Save/Load 异步      |
| WebSocket header (Authorization) | gorilla 支持自定义 header | 浏览器 WS 不支持 → 用 query token | 服务端需对应支持 ?token=     |
| ChatStream 返回 | (eventCh, errCh)      | AsyncIterable<StreamEvent>      | 错误经 throw 而非 errCh      |
| ChatStreamWithUsage | 4 channels         | tagged AsyncIterable {kind, event} | 单流分发, 调用方 switch on kind |
| sync.Mutex    | 显式 Lock/Unlock      | Promise chain 串行化            | 行为等价                      |
| time.Time     | RFC3339 string        | ISO 8601 string                 | wire 格式一致                |
| json.Number   | string 包装           | string 字段                     | 金融金额安全 (JS number 精度) |
| int64         | 原生                  | number (≤2^53 安全)             | Acosmi token 量级远低于此     |
